# MSP 15 Years · invitation site

The invitation page for the Maastricht Science Programme's 15th-anniversary drinks
(Saturday 10 October 2026, Tapijn, Maastricht). Static site, no build step.
Deployed with GitHub Pages from `main`; push = live.

## Editing

- All event state lives in `CONFIG` at the top of [`js/main.js`](js/main.js):
  the registration URL (null = "opens soon" state), the attendee counter
  (null = hidden), the canonical share URL, and the contact mailbox.
- Content is plain HTML in `index.html`. Design tokens in `css/style.css`.
- Image derivatives are generated by `py tools/make_images.py` from local
  `*-src.*` originals (gitignored). Derivatives are resized and metadata-stripped.
- `event.ics` must keep CRLF line endings (RFC 5545); regenerate with the
  snippet in the project notes rather than editing by hand.

## House rules

- This repo is public. No personal data, no attendee lists, no exports, ever.
- No em dashes and no AI-sounding phrasing in page copy.
- The design follows the visual language of UM's 50th-anniversary site as a
  deliberate homage: own mark, own code, free fonts (Fraunces + Archivo, latin
  subsets committed in `assets/fonts/`).
